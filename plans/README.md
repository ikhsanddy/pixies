## Recon and verification baseline

- Target: `web/`, the React 19 + Vite 8 marketing landing page. `README.md:152,183-185` and `CONTRIBUTING.md:29,38` identify it as the landing page. `client/`, `server/`, `docs/`, and `brand/` are out of scope.
- Runtime/tooling: Bun 1.4.4, Vite 8.3.4, React Router 7, Sass. No automated test suite (`README.md:187-188`).
- Production build: `cd web && bun run build` passes in about 3.46s. Existing warnings are Vite's native-config `__dirname` warning and Sass `lighten()` deprecations.
- Baseline artifacts: one JS file at 439,947 bytes / 134.59kB gzip as reported by Vite; CSS at 23,747 bytes / 4.94kB gzip; screenshots at 179,863 + 189,197 + 430,382 bytes.
- Browser transfer baseline: the JS encoded body was 133,369 bytes and transfer size 133,669 bytes. The cold home load transferred about 1,002,421 bytes across the document, JS, CSS, images, fonts, and favicon.
- Local desktop 1440x900: FCP 376ms, LCP 492ms, CLS 0.02.
- Local mobile 390x844: FCP 284ms, LCP 296ms, CLS 0.05.
- Throttled mobile audit run: 390x844, DPR2, cache disabled, 4x CPU throttling, 1.6Mbps down, 150ms latency. FCP was 1,664ms and LCP 4,544ms. The hero image started at 1,403ms and took 3,122ms; all three screenshots started together at default priority. Treat this as one local diagnostic run, not a field percentile.
- Lint command: `cd web && bun run lint`. It currently exits 2 because ESLint 10 requires `eslint.config.*` while the repo has `.eslintrc.cjs`. This is a known baseline, not a performance finding, and is out of scope for these plans.
- Deployment: `.github/workflows/deploy-landing.yml:3-5,26-34` describes a manual Cloudflare Pages deployment of `web/dist`; no hosting rewrite rule is present in the repo.

## Findings considered and rejected

- **Lazy-load secondary routes:** an in-memory Vite comparison showed only about 2.1kB gzip saved on the initial home route. Home is needed immediately and shared React/FontAwesome code stays in the entry, so the navigation/fallback complexity is not justified yet.
- **Replace Font Awesome with local SVGs:** a build with the entire Font Awesome runtime removed measured a ceiling of about 5.8kB gzip saved before adding replacement SVG code. Replacing 23 icons carries visual-parity and attribution risk for too little gain in this pass. Revisit if icon count or runtime work grows.
- **Preload all five Inter faces or preload 900 globally:** home uses only 400, 700, and 900, while 900 is absent from normal secondary routes. Unused faces add traffic, and a global 900 preload wastes 17,176 bytes and can trigger unused-preload warnings outside home/404.
- **Throttle or memoize the navigation scroll handler:** repeated `setScrolled` calls with the same boolean bail out of React rendering (`web/src/common/components/Navigation/Navigation.jsx:28-33`); no measured hotspot justifies a change.
- **Delete TTF font fallbacks for performance:** modern browsers request WOFF2 only. The TTF files increase deployed size but not the measured home-page transfer.
